Added ``jpype.JPypeDeprecationWarning``, the category for JPype deprecations.  It derives from ``FutureWarning`` so that it is shown by default, also when JPype is called from inside a library; ``DeprecationWarning`` is hidden there.  The existing deprecations (``attachThreadToJVM``, ``detachThreadFromJVM``, ``isThreadAttachedToJVM``, and ``JObject`` with a Python type) now use it and are therefore visible.  Silence only JPype's deprecations with ``warnings.filterwarnings("ignore", category=jpype.JPypeDeprecationWarning)``.
