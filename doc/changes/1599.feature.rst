Added :obj:`jpype.JPypeDeprecationWarning`, the category for JPype deprecations.  It derives from :obj:`FutureWarning` so that it is shown by default, also when JPype is called from inside a library; :obj:`DeprecationWarning` is hidden there.  The existing deprecations (``attachThreadToJVM``, ``detachThreadFromJVM``, ``isThreadAttachedToJVM``, and :obj:`JObject <jpype.JObject>` with a Python type) now use it and are therefore visible.  Silence only JPype's deprecations with ``warnings.filterwarnings("ignore", category=jpype.JPypeDeprecationWarning)``.
