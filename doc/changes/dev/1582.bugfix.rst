Editable and plain CMake builds now rebuild ``org.jpype.jar`` and the Java test harness from source on every build when a JDK is available, so changes to the Java code are picked up by ``pip install -e .``.  Previously, the jar from the last build in the repository root was reused as a cache, and Ant only ran when its output was missing.  Such builds require Ant.  Wheel builds from an sdist still use the cached jar and need neither.
