The Azure Pipelines jobs for Python 3.8 and 3.9 now get a uv-managed interpreter of the requested architecture, because ``UsePythonVersion`` can no longer download these versions.  Without this, the test jobs silently ran on the agent's system Python and failed.  A new check fails any job whose interpreter is not the requested version.  Windows and macOS now also test the oldest and newest supported Python (3.8 and 3.15).
